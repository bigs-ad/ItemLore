# 用途资料维护

用途条目定义在 `UsageData.lua`，以数值物品 ID 为键，不按名字匹配。
显示文字通过 `Locale.lua` 翻译；新增或修改文案时必须同时更新英文，不能只修改中文键。

每条包含 name（展示名称）、summary（简短提示）、usage（详细用途）、
version（证据适用版本）、tested（是否完整实测用途）、verification（具体核实范围）、
sources（来源列表，分别记录 kind 和 reference）。

录入规则：
- 分开记录截图可确认事实、外部资料和玩家推测，不将后两者写为实测。
- 阅读正文或看到物品提示，不等于验证了任务完成、重复使用或删除后果。
- 证据只适用于已记录版本；客户端更新后重新核对受影响条目。
- 来源只在“详情”显示，不在游戏运行时联网抓取。
- summary 尽量一句话；用途不明写“未知用途”。
- 此表只补充说明并保留物品，不授权删除，即使 tested=true 也不例外。
